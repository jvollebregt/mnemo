## 🎯 KEY DECISIONS MADE FOR YOU

### Navigation Flow (Finalized)

```
Launch Popup (User sees this at app start)
├─ "Continue [Last Poem]" → Go to Practice Screen
├─ "Challenge: [First Poem]" → Go to Practice (fresh state)
└─ "Go to Menu" → Menu Screen
    ├─ My Poems List (title, author, progress, last studied)
    ├─ Account / About / FAQ / Contact links
    └─ Click poem → Dashboard
        ├─ Metadata (title, author, form, year, length)
        ├─ Mastery Metrics (Meter %, Rhyme %, Sound %)
        ├─ SM-2 Scheduling (next review, interval, repetitions)
        ├─ Error Patterns (last 7 days)
        └─ "Practice This Poem" button → Practice Entry Popup
            ├─ Continue (remember last toggles)
            ├─ Fresh Start (all off)
            └─ Custom (edit toggles)
                └─ Start Practice → Practice Screen
                    ├─ Poem display + annotations
                    ├─ Meter dots (clickable)
                    ├─ Rhyme letters (editable)
                    ├─ Sound patterns (selectable + color)
                    ├─ Mode selector (Meter/Rhyme/Sound/Mixed)
                    ├─ Layer toggles (show/hide)
                    └─ [NEXT] button
```

### Mobile-First Philosophy (Locked In)

- **Phone is dual-purpose:**
  - Visual aid (poem text + annotations)
  - Dictaphone (Phase 2: record recitations)

- **Layout principles:**
  - Stacked vertical (no sidebars on mobile)
  - Bottom fixed bar for frequent actions
  - 48px touch targets minimum
  - Responsive: 320px → 480px → 768px → 1024px+

- **Interactions:**
  - Tap to toggle/edit annotations
  - Long-press for help
  - Swipe left/right for prev/next
  - Haptic feedback on all interactions

### Design System (Finalized)

**Colors:**
- Primary: Deep teal (#207E8A)
- Background: Warm cream (#FDF8EC)
- Cards: Off-white (#FFFBF7)
- Text: Dark charcoal (#1F2121)
- Sound patterns: 6 muted pastels

**Typography:**
- Poem text: EB Garamond, 18px, 1.6 line-height
- UI: Inter, 16px (accessibility)

**Components:**
- Buttons (primary/secondary)
- Cards (shadow + border)
- Checkboxes (blue when checked)
- Progress bars (color-coded)
- Annotation dots (● filled, ○ hollow)
